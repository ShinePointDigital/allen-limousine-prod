Build a production-ready, portable full-stack web app for a high-end Chicago chauffeur/livery company named “ALLAN Livery” (ALLEN LIMOUSINE). Recreate the luxury public website and add a secure admin dashboard for managing the business. The application must be deployable to the customer’s own hosting provider without relying on Manus, Replit-only services, proprietary platform APIs, or hardcoded platform URLs.

Set up the portable full-stack project structure, skipping manual asset uploads. Generate high-quality Unsplash image URLs or luxury SVG illustrations for all hero, airport, city, and fleet visuals that match the Midnight Charcoal (#0D0E0E), Warm Bone (#F4F0E8), and restrained Brass (#C9A56A / #D7BB85) palette. Configure the project, including vite.config.ts, to bind to host: '0.0.0.0', port: 5173, with hmr: { clientPort: 443 } so all changes are instantly visible in Replit's Webview preview. Use Prisma ORM with PostgreSQL for all database models.
